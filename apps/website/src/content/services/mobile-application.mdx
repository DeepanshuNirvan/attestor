A mobile assessment that stops at the binary is half an assessment. The binary tells you about
hardcoded keys, insecure storage and missing certificate pinning. The traffic tells you about the
backend, and the backend holds the data.

So we do both. We analyse the shipped package on both platforms, then run the app on an instrumented
device with its traffic intercepted. The endpoints we capture go into the API testing.

Mobile-only endpoints are often the least protected part of a product. They were written early, are
called by fewer people, and frequently never got the rate limiting and device checks the web login
has.

## What the static pass finds

- Keys in resource strings and native libraries.
- Session tokens written to shared preferences in plain text, then copied into the device backup.
- Exported components that other installed apps can start.
- Deep links that open an arbitrary URL inside the authenticated WebView, with the session attached.
- Certificate pinning present on the main API host and missing on the payment host.

## What the runtime pass finds

Whether pinning holds and how much effort a bypass takes. What stays in memory after the payment
screen closes. Whether the biometric prompt actually gates anything, or just sets a variable that a
single hook can flip.

## Data safety declarations

Both app stores require you to declare what data your app collects and shares. Few teams check
whether that declaration matches the binary, and often it does not. The usual cause is a third-party
SDK collecting an advertising identifier and coarse location that nobody on the team knew about.

We compare your declaration against what the app actually does and report the difference. An
inaccurate declaration is a store enforcement and regulatory problem, and it is cheaper to find here
than in a store review.

## What we need from you

- The release build for both platforms, ideally the exact artefact you ship.
- Two test accounts per role, for the backend testing.
- A device or emulator profile, if you have platform restrictions.
- A heads-up if your app has root or jailbreak detection. We will bypass it for the runtime work,
  and we would rather do that with your knowledge.
